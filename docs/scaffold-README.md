## Wire-in checklist

1. **Move the site files** to a repo dir `background-remover/` (index.html, robots.txt, sitemap.xml, manifest.webmanifest,
   nginx.conf, nginx.prod.dockerfile). Add `favicon.svg`, `apple-touch-icon.png`, `og-image.png`, and PWA icons.
2. **k8s manifest** → `personalServerNotes/k8s/background-remover/deployment.yaml`.
3. **Register in manage.sh** — add the 3 entries from `manage-registration.snippet`
   (SERVICES, ALL_SERVICES, MANIFEST_PATHS).
4. **Ingress + TLS** — add a route for `background-remover.dloizides.com` to `personalServerNotes/k8s/ingress.yml`
   (+ `staging-ingress.yml`) and a `background-remover-tls` secret.
5. **Umami** — create a website entry in the analytics dashboard, then replace `REPLACE_WITH_UMAMI_WEBSITE_ID` in `index.html`
   with the real `data-website-id`.
6. **Deploy** — `bash personalServerNotes/scripts/manage.sh deploy background-remover`.
